# Blue Pear Tree

Vendor-neutral AI advising website for healthcare organizations.

## Update GitHub / Cloudflare Pages

1. Unzip this folder.
2. Put these at the **repo root**:
   - `index.html`
   - `assets/` (all files inside)
   - `robots.txt`
3. Commit and push. Cloudflare Pages rebuilds automatically.

## Included in this build

- Crisp blue/white clinical palette
- Happy clinician photography (hero, about, team band)
- Trust row: HIPAA-aligned · NIST AI RMF · Vendor-neutral · 1-day response
- Principal Advisor credentials card
- Lean splash with progress bar
- Public contact: info@bluepeartree.com (forward via Cloudflare Email Routing). Web3Forms may still deliver to your Gmail destination.
